# artifact-digest-check

下载工作流产物后，用已知的 SHA-256 摘要核对磁盘上的文件字节。脚本可以用退出码处理不匹配，JSON 只输出状态和实际读取的字节数。

[English](README.md) · [资料与取舍](RESEARCH.md) · [测试](TESTING.md)

## 运行

在本目录用 Python 3.11 或更新版本运行，无需安装依赖。

```sh
python artifact_digest_check.py fixtures/hello.txt sha256:5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03
```

```json
{"status":"match","bytes_read":6}
```

命令格式为 `python artifact_digest_check.py FILE EXPECTED`。摘要须为 64 位 ASCII 十六进制数字，可加严格小写的 `sha256:` 前缀。数字中的字母不区分大小写，整个参数不得含空白。带空格的路径请加引号，以连字符开头的路径前加 `--`。

| 退出码 | 状态 | 含义 |
| --- | --- | --- |
| 0 | `match` | 文件字节与摘要匹配。 |
| 1 | `mismatch` | 文件字节与摘要不匹配。 |
| 2 | `invalid` | 参数、路径或文件无效，文件超限，或发生 I/O 错误。 |

`--help` 打印帮助并返回 0。标准输出管道关闭时，命令静默返回 2，帮助输出也适用。文件若在读取时增长并超限，字节计数包含用于确认超限的 1 个额外字节。

## 边界

摘要应对应磁盘上的原始字节。摘要若来自压缩包，请直接检查那个包。工具按原始字节读取，不解压、不校验 ZIP 格式、不下载，也无法验证产物身份或来源。请从可信渠道取得摘要。

仅以只读方式打开普通文件，支持空文件，最大 1 GiB（含）。单次读取最多 1 MiB。访问文件系统前拒绝 URI、UNC 和设备路径，接受 Windows 盘符绝对路径。符号链接、目录联接和挂载点由操作系统解析，本地形式的路径可能指向远程存储。如果文件可能被并发修改或替换，请在可信目录检查已经写入完毕的文件。
